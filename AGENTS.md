# EQoon

JUCE audio plugin (7-band EQ + FFT analyzer). Built with Projucer + Xcode on macOS.

## Build

```sh
# Open EQoon.jucer in Projucer, save to regenerate Xcode project, then:
open Builds/MacOSX/EQoon.xcodeproj
# Build from Xcode (Cmd+B) — Debug goes to Builds/MacOSX/build/Debug/
```

Regenerate the Xcode project by opening `EQoon.jucer` in Projucer and saving.

## Install

```sh
ditto Builds/MacOSX/build/Debug/EQoon.vst3 ~/Library/Audio/Plug-Ins/VST3/EQoon.vst3
```

Also produces AU variant (`EQoon.component`) and standalone.

## Project structure

| Path | Purpose |
| ---- | ------- |
| `Source/PluginProcessor.h/.cpp` | DSP: 7-band filter chain (low-cut, low-shelf, 3x peak, high-shelf, high-cut), FFT analyzer integration, APVTS state |
| `Source/PluginEditor.h/.cpp` | UI: custom rotary sliders, response curve + FFT visualization, label layout |
| `Source/FFTAnalyzer.h/.cpp` | 2048-point FFT with Hann window, FIFO buffering |
| `EQoon.jucer` | Projucer project file — source of truth for module deps, export config |
| `JuceLibraryCode/` | Auto-generated by Projucer. Do not edit. Your reference point for the JUCE documentation, check the Headerfiles. |
| `inspo/` | Collection of Plug-Ins and Hardware designs to take inspiration from. |
| `Builds/` | Per-platform IDE projects. Also auto-generated. |

## Key constraints

- **Dependency: `../JUCE/`** must exist (JUCE framework parallel to this repo). JUCE modules are loaded via global path `../JUCE/modules`.
- **Do not hand-edit** `JuceLibraryCode/`, `Builds/`, or any auto-generated files. Edit the `.jucer` file or `Source/` files, then regenerate via Projucer.
- **No test framework** — this is a v0.1 audio plugin with no tests, no CI, no linter.
- **Mono processing chain** — `MonoChain` is a `ProcessorChain<CutFilter, Filter, Filter, Filter, Filter, Filter, CutFilter>`. Stereo uses two separate mono chains (`leftChain`, `rightChain`).
- **Slope enum** in `PluginProcessor.h`: `Slope_12` (1 biquad), `Slope_24` (2), `Slope_36` (3), `Slope_48` (4).
- **FFT**: 2048-point transform, Hann window, pre/post EQ analyzers, rendered at 30 FPS via `Timer`.
- **Spectrum visualization** — `drawSpectrumPath` fills a closed path with a vertical `ColourGradient` from bright spectrum color → near-black. Thin contour stroke with subtle glow. Mouse hover shows vertical line + frequency caption. Grid lines at 6 dB intervals + standard log-spaced frequencies with labels.
